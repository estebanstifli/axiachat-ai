Frequently Asked Questions

Do I need my own API keys?
Yes. You'll need your own API keys from OpenAI, Anthropic (Claude), or Google (Gemini). The plugin doesn't proxy or bundle access—you connect directly to the AI providers using your credentials.
Can I disable conversation logging?
Absolutely. Logging is optional and can be toggled on/off anytime. When disabled, no new conversations are stored. Existing logs remain until you manually delete them.
How does the RAG training work?
Content is chunked, embedded using OpenAI's text-embedding model, and stored with similarity scores. When a user asks a question, the most relevant chunks are retrieved and provided as context to the AI model for accurate, source-based answers.
Will it slow down my site?
No. The frontend is lightweight (~50KB total), loads asynchronously, and doesn't block page rendering. Database queries are optimized and the plugin works seamlessly with page caching solutions.
Can I use it in multiple languages?
Yes! The plugin is translation-ready with Spanish included. The AI models support 50+ languages naturally—just train them with content in your language and they'll respond accordingly.
Is there a limit on the number of bots?
No limits! Create as many bots as you need—each with unique configurations, training data, and UI styles. Perfect for different departments or use cases.
